# Zenodrop v9

Добавлено:
- окно пополнения в стиле Zenodrop: СБП / Карты / Крипта / Скины;
- заявки на пополнение с промокодом;
- промокоды на вкладке кейсов;
- Telegram-бот для заявок на вывод;
- кнопки «Выдать» / «Отклонить» в Telegram;
- привязка Telegram ID к Steam ID через `/link 765...`;
- выдача баланса через `/give STEAMID 1000`;
- отключение вывода `/withdrawlock STEAMID on`;
- выдача web-admin `/adminsteam STEAMID`;
- создание промокодов `/promo CODE 12`;
- серверное хранение баланса/заявок в `zenodrop_data.json`.

## Render Environment Variables

Обязательные:
- `CS2SH_API_KEY`
- `STEAM_API_KEY`

Для Telegram:
- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather
- `TG_ADMIN_IDS` — Telegram ID администраторов через запятую, например `123456789,987654321`

После первого запуска администратор может использовать:
- `/adminpanel`
- `/withdrawals`
- `/give STEAMID 1000`
- `/withdrawlock STEAMID on`
- `/adminsteam STEAMID`
- `/admin TELEGRAM_ID`
- `/promo STORM-12 12`
- `/link STEAMID`

### Важно про автоматическую отправку Steam-скинов
Сайт теперь создаёт и отслеживает заявку, а Telegram-кнопка «Выдать» подтверждает её. Реальная отправка предмета через Steam Trade Offer требует отдельного Steam-аккаунта-бота, его инвентаря, assetid предметов и trade-offer авторизации. Эти данные нельзя безопасно встроить в HTML. Текущая версия специально не делает фальшивую «автоматическую отправку», если Steam trade-интеграция не настроена.

## Платежи
Сейчас создаются заявки на пополнение, а подтверждение выполняется администратором. Реальные эквайринги СБП/карт и крипто-процессинг требуют API/merchant credentials конкретного провайдера; их можно подключить в следующем шаге без изменения интерфейса.
