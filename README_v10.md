# Zenodrop CS2.SH v10

Что изменено:
- Пополнение теперь имеет отдельную вкладку **Telegram**. Остальные способы (СБП, карты, крипта, скины) не переводят пользователя в Telegram.
- Окно пополнения переработано: отдельные вкладки, быстрые суммы, красивый блок метода, промокод и индикация бонуса.
- Сайт автоматически создаёт новый случайный промокод каждые 15 минут.
- Процент случайный: **от 10% до 23%**.
- Автокод действует 15 минут; просроченные коды перестают работать.
- Бонус по промокоду начисляется при подтверждении пополнения, а не при создании заявки.
- Telegram-бот может только уведомлять администратора о заявках и отдельно использоваться как способ пополнения.

## Render env
Обязательно:
- `CS2SH_API_KEY`
- `STEAM_API_KEY`

Для Telegram:
- `TELEGRAM_BOT_TOKEN`
- `TG_ADMIN_IDS`
- `TELEGRAM_BOT_URL` — например `https://t.me/YourZenodropBot`

`TELEGRAM_BOT_URL` нужен только для кнопки отдельного способа «Telegram» в окне пополнения.
